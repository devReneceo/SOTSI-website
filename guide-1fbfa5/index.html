The five rules

Follow these and you cannot go badly wrong.

1
The Designer is not the live site

Videos, the blog, episodes, search and animations only run on the PUBLISHED site. In the Designer those areas look empty, grey or stacked — nothing is broken. Always judge on the live site.

2
Follow the labels

Everything is labelled for you: GREEN ✎ = yours to edit · AMBER ⚙ = automatic, don’t fight it · RED 🔒 = never touch. No label or unsure? Ask 22D first.

3
Blog posts live in the 22D board

Write and publish posts in the board. Editing a post inside Webflow gets overwritten by the next sync. And never change the slug (the last part of a URL) of anything published.

4
Publish, then check the live page

No change is visible until you click the blue Publish button (top right). After publishing, open the live page in a normal tab and refresh.

5
Every mistake is fixable

Cmd+Z (Mac) / Ctrl+Z (Windows) undoes your steps. Bigger accident? Site backups restore everything. Worst case: email 22D — nothing is ever truly lost.

The special parts, one example each

Most of the site repeats the lessons above. These are the only parts that work differently.

A button’s label or destination Easy

Most buttons on the site are shared components — they open a small Properties panel instead of direct editing.

  1. Click the button ONCE. If a panel appears on the right with Label and Link fields — edit them there. Done.
  2. No panel? It’s a plain link: double-click to edit the text; change the destination with the link (chain) icon in Settings.
  3. For links to other websites, keep “Open in new tab” on. Publish and test the button live.

Navbar & Footer — one change, every page Careful

The top navigation and the footer are ONE component reused on every page. Edit once — it changes site-wide. Usually that’s exactly what you want.

  1. Double-click the navbar (or footer) to step inside the component.
  2. Menu links and footer buttons work like any text/button (Lesson 1, recipe above).
  3. Don’t add or remove menu items and don’t touch the grey 🔒 blocks inside (menu behaviour, search box) — ask 22D.
  4. Publish once; every page updates.

The Home hero slideshow (4 slides) Careful

On the live site the 4 slides rotate every 12 seconds. In the Designer they are stacked on purpose, each with an orange “SLIDE N of 4” label, so you can edit each one.

  1. Texts: double-click any title, kicker or line inside a slide and type. Keep gold words inside their gold highlight.
  2. Buttons: click once → Properties (Label + Link). Slide 1’s buttons are hidden by design — leave them hidden.
  3. Photos: each slide’s photo has separate phone/tablet crops. Send new hero photos to 22D — we set all sizes so faces stay framed.
  4. Publish, then watch the live hero rotate through all four slides.

The impact numbers (they count up) Careful

Each stat animates from 0 up to a value stored in a hidden attribute called data-count. The visible number AND the attribute must match.

  1. Double-click the number on the canvas and type the new value.
  2. With the number still selected, press D → scroll to Custom attributes → set data-count to the same value (data-suffix holds things like “M+”).
  3. Publish and watch the live count-up.
  4. Feels fiddly? Email 22D the new number — it’s a 10-second fix on our side.

Hand-picked rows (Home practices & Soul Feed) Careful

The 4 practice cards and the 3 Soul Feed posts on Home are pinned selections — they do not update by themselves, on purpose.

  1. The row’s heading and intro text are yours — edit like any text.
  2. The cards’ content lives in the CMS (practices) or the 22D board (posts). Edit the item, not the card.
  3. Want DIFFERENT items featured? Tell 22D which ones — swapping the pinned set is our job.

Forms (newsletter, downloads, waitlist) Leave alone

Every form feeds the email system (ActiveCampaign). The texts around a form are yours; the form itself is wired.

  1. Headings, paragraphs, button labels near a form: edit freely (Lesson 1).
  2. Never rename, add or delete form FIELDS, and never delete a form — sign-ups would silently stop arriving.
  3. Need a new field or a new form? That’s a 22D task — email us.

When something looks wrong

A page looks empty, grey, or ‘broken’ in the Designer.

Expected. The dashed AUTO boxes (blog directory, episodes, search, videos, waves) are filled by code on the live site only. See “Why the Designer looks different”.

I edited a blog post in Webflow and it reverted.

Blog posts are managed in the 22D board; the next sync overwrites Webflow edits. Make the change in the board and click “Update on Website”.

My change doesn’t show on the live site.

Did you click Publish? If yes, hard-refresh the live page (Cmd/Ctrl+Shift+R). If still missing, publish once more — it occasionally needs a second try.

I deleted something by accident.

Cmd/Ctrl+Z immediately. If it’s too late, Site settings → Backups → preview → Restore.

A form, video or feed stopped working after my edit.

You may have touched a 🔒 element. Undo your change and tell 22D what happened — restoring is quick.

Known quirks (not your fault)
  • On phones and tablets, the cookie banner covers the hero slide dots until the visitor accepts or declines it.
  • The video on “In Celebration of Linda Francis” is blocked on the staging domain (Vimeo whitelist) — it will work on the final domain.
  • The Designer’s Preview (eye icon) does not load this site’s effects either — the hero looks stacked/overlapping there. That’s expected; judge on the published site.

Eight words, plainly

Designer — Webflow’s full editing app — canvas in the middle, panels on the sides.
Navigator — The tree of every element on the page (press Z). All elements are labelled ✎ / ⚙ / 🔒 for you.
Edit mode (?update) — A safe, content-only editing view of the live site. Add ?update to any page address.
Component — A reusable block (Navbar, Footer, Buttons). Editing the component changes every copy of it.
CMS / Collection — The site’s content database (Books, Courses, Blog Posts…). Items are edited as forms in the CMS panel.
Slug — The last part of a URL (…/blog/kindness → “kindness”). Never change it on published content.
Publish — The button that pushes your saved changes to the live site.
Alt text — A one-line description of an image, read by screen readers and Google.
